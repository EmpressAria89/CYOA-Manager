# Maintainer constraints

Linux-only. Preserve project IDs, edition fingerprints, archived assets and saved builds. Catalog records and personal library cards are different identities. Never turn an archived download into a current edition without explicit review. Keep downloaded projects, browser state, credentials, generated output and private evidence out of source exports.

Git is deliberately detached. Do not attach, commit or publish unless explicitly requested. Use a separate publication checkout and detach after publication. Run the source/export gate before publishing.
