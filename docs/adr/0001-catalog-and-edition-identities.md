# Catalog records never replace edition identity

Status: accepted. Date: 2026-10-16.

The catalog supplies mutable links and metadata, whereas personal library cards and builds refer to independently identified editions. Merging them by title, host or the latest catalog date could misroute builds or replace a mod with a different work. Keep catalog records separate; link cards conservatively using complete playable URLs, preserving meaningful query parameters and routes. Supplemental records enrich only unambiguous matches. Archives and uncertain alternatives are recovery candidates, imported as separate cards with provenance. Updates require a preview of actual content and retain the prior edition. Catalog metadata never overwrites personal credit labels or completion state.

This costs explicit choices for ambiguous records and recovery, while preventing silent data loss. Neither newest spreadsheet row nor a matching title proves an edition is current.
