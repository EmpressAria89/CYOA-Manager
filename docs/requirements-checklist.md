# Rework acceptance checklist

- [x] Standalone Linux launch without a localhost development server.
- [x] Catppuccin Latte, Frappé, Macchiato and Mocha throughout manager controls.
- [x] Independent manager/reader fonts; regular reader overrides and adjustable manager text size.
- [x] Early themed viewer backgrounds; retain cards during refresh and cache cover resolution.
- [x] Shared right-side Builds/Search dock, tested at narrow widths.
- [x] Search fields with short placeholders and full hover hints.
- [x] Builds form layout and viewer-native capture/load.
- [x] Build identity, edition fingerprint and cross-CYOA rejection.
- [x] Legacy recovery/review; empty source payloads cannot restore missing choices.
- [x] Unclipped card menu.
- [x] Archive removes manager-owned copies from the library; archive opens independently.
- [x] Changed re-downloads show differences and preserve the previous edition.
- [x] Duplicate scan; retention of 3–5 unstarred editions with starred/open protection.
- [x] Prefer ICC2 Plus; Original remains a force option. Format validation is structural, not exhaustive gameplay simulation.
- [x] Player status Completed(N), derived from saved builds; omit author completion status.
- [x] Separate original author and modder, with a mod checkbox.
- [x] Persistent author aliases; keep source credits and previous aliases.
- [x] Windowed startup for manager and readers, with no forced maximization/fullscreen.
- [x] Compact author/fandom/mod/modder/player-status/extra-tag filters.
- [x] Tag autocomplete/chips; normalize catalog bracket groups, aliases and duplicates.
- [x] Import available descriptions and structured metadata; exact catalog URLs fill missing author/fandom/description without replacing manual fields or tags.
- [x] Internal saved website snapshots; online reader for live services/dynamic resources.
- [x] Fit complete cover artwork into consistent frames; recover missing covers from later rows/choices.
- [x] Distinguish automatic lossless archives from optional lossy artwork reduction in Settings.
- [x] ICC2 Plus Cheat Menu reveals hidden choices/addons inside open sections without bypassing selection requirements or opening row/tab navigation.
- [x] Automatic thumbnail optimization, including Linux AVIF decoding, without modifying original artwork.
- [x] Automatic lossless ZIP compression of new and existing archives; verify checksums before retiring loose copies.
- [x] Verify archive extraction/restore, corruption preservation and open-version cache protection.
- [x] Verify final migration and normal launch against the real library.
- [x] Centralize checks in tests/, recovery snapshots outside the workspace, and documentation in docs/.
- [x] GitHub README and workflow identify Linux x86_64 scope; upstream platform release paths retired.

Rendering and website compatibility have been tested on fixtures and native Naruto; all authored pages and live catalog sites are not exhaustively tested. No performance benchmark claim is made.
