# Glossary

- **Catalog entry:** a discoverable CYOA listing with source metadata and links; it is not a downloaded library card.
- **Library card:** the player's independently identified local project, notes, preferences and builds.
- **Edition:** one specific content version of a CYOA. Older and modded editions remain distinct.
- **Source:** the publisher or catalog location from which metadata or playable content came.
- **Recovery candidate:** an alternate link or archived copy that might restore access, with no guarantee of matching the current edition.
- **Importer:** the person who made a CYOA interactive; this credit is distinct from author and modder.
- **Catalog status:** the listing's description of a work, such as WIP, mod or broken link; unrelated to the player's completion status.
- **Compatibility result:** evidence about the features used by an edition and which viewer can preserve them. A structural match is not a playability guarantee.
- **Update preview:** a comparison of a downloaded candidate with the current edition, before deciding whether to apply it.
